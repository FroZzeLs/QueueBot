# QueueBot (Web + Spring + tg-bot)

Приложение работает как:
- **Web (SPA)**: просмотр/запросы/админка
- **Backend (Spring REST + PostgreSQL)**: хранение и вся бизнес-логика очередей
- **tg-bot (отдельный микросервис)**: отправка уведомлений и обработка кнопок *«Принять/Отклонить»*

## 1) Требования
- Docker Desktop (или Docker Engine + Compose)

## 2) Настройка окружения
В корне проекта есть `docker-compose.yml`. Перед запуском рекомендуется создать файл `.env`:

1. Создайте файл `.env` рядом с `docker-compose.yml`
2. Заполните переменные (минимум — ключ суперадмина и параметры telegram-бота):

```env
# Ключ для регистрации первого суперадмина
SUPER_ADMIN_KEY=change-me

# Общий секрет, которым backend и tg-bot защищают внутренние HTTP-вызовы
TG_BOT_INTERNAL_SECRET=tg-secret

# Telegram-бот (нужно, чтобы отправлялись уведомления)
BOT_NAME=YourBotName
BOT_TOKEN=123456:ABCDEF...
```

> Если `BOT_TOKEN`/`BOT_NAME` не заданы, контейнер `tg-bot` запустится, но Telegram-уведомления не будут отправляться.

## 3) Запуск одной командой
Выполните из корня `QueueBot`:

```bash
docker compose up --build
```

После старта откройте:
- Web: `http://localhost:8080`

## 4) Первый запуск (регистрация суперадмина)
1. Откройте сайт `http://localhost:8080`
2. Если суперадминов в базе ещё нет, UI предложит ввести **ключ супер-админа**
3. Зарегистрируйте суперадмина и установите пароль
4. Затем выполните в Telegram команду **`/start`** для вашего аккаунта (это нужно, чтобы tg-bot сохранил `chat_id` и мог отправлять уведомления)

## 5) Мануал по использованию

### 5.1. Админка (только админ/суперадмин)
Вкладки:

1) **Студенты**
- Добавить студента: `ФИО`, `telegram_tag`, `подгруппа (1/2)`

2) **Предметы**
- Добавить предмет: `аббревиатура` + `тип сдачи`
  - **Индивидуальный**
  - **Бригадный** (тогда нужно создать бригады)

3) **Бригады** (для бригадных предметов)
- Соберите бригады через UI, чтобы **каждый студент** входил **ровно в одну** бригаду для этого предмета
- Нажмите **«Сохранить бригады»**

4) **Роли (super)**
- Суперадмин может назначать/снимать обычных админов (тумблер `Админ`)

### 5.2. Очереди (для всех)
1. Выберите предмет
2. Выберите тип очереди:
   - **Общая очередь**
   - **Подгрупповая очередь** (и подгруппа 1/2)
3. Нажмите:
   - **«Запрос на смену»** чтобы отправить запрос обмена
   - **«Сняться»** чтобы сняться с очереди
   - (админ) **«Отметить последнего»** чтобы зафиксировать сдающего и продвинуть ротацию

### 5.3. Обмен местами
1. Для **Индивидуального** предмета: выберите целевого студента — запрос уйдёт в личку.
2. Для **Бригадного** предмета:
   - сначала выбирается целевая бригада из активной очереди
   - затем выбирается один участник бригады, которому придёт запрос
3. В Telegram получатель видит 2 кнопки: **«Принять»** и **«Отклонить»**
4. При **принятии** backend создаёт временный свап, влияющий на отображаемую очередь до следующего шага *«Отметить последнего»*.

## 6) Примечания по Telegram
- Все участники (пользователи, которым отправляются запросы) должны сделать **`/start`** в tg-bot.
- Иначе у них не будет `chat_id`, и уведомления не уйдут.
