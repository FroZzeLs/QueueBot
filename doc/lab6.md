### 2. Пути улучшения UX и их обоснование

В рамках лабораторной работы проект был переведен со стадии **функционального MVP** на стадию **завершенного пользовательского интерфейса**. 

**Выбранные пути улучшения:**
1.  **Внедрение адаптивной цветовой схемы (Dark/Light Mode):** Снижение зрительной нагрузки и повышение удобства использования в разное время суток.
2.  **Структурное разделение интерфейса (Разделение на Табы):** Выделение функций администрирования (Студенты, Предметы, Бригады) в отдельные вкладки для снижения когнитивной нагрузки.
3.  **Визуализация ролевой модели:** Добавление меток «Admin», «Super», «Superadmin» рядом с именами пользователей для мгновенного понимания прав доступа.
4.  **Интерактивный конфигуратор бригад:** Замена ручного ввода ID студентов на визуальный выбор чекбоксами со счетчиком распределения.

### 3. Описание «До» vs. «После» (Улучшения)

| Характеристика | Состояние «ДО» (MVP-стадия) | Состояние «ПОСЛЕ» (Текущая версия) |
| :--- | :--- | :--- |
| **Цветовая схема** | Стандартная светлая тема (библиотечные стили без кастомизации). | Полноценный дизайн в Dark и Light режимах (скриншоты 1 и 4). |
| **Навигация** | Все админ-функции на одной длинной странице, разделенной заголовками. | Четкая структура: боковой сайдбар для предметов и табы для админки (скриншот 2). |
| **Управление очередью** | Кнопки действий находились в каждой строке списка, загромождая экран. | Управляющие кнопки вынесены в Header-блок (скриншот 1), очищая рабочую область. |
| **Работа с бригадами** | Формирование бригады через ручной ввод текстовых данных студентов. | Интерактивный список с чекбоксами и визуальным списком готовых групп (скриншот 3). |
| **Визуализация данных** | Просто список ФИО. | Список с баджами ролей, подгруппами и Telegram-тегами. |

### 4. Визуализация результатов (Уровни UX)

*   **Уровень поверхности (Surface):** На скриншотах 1 и 4 видна работа над эстетикой — плавные переходы между темами, использование акцентного синего цвета для главных кнопок («Swap», «Add»).
*   **Уровень компоновки (Skeleton):** Форма добавления студента (скриншот 2) сгруппирована горизонтально, что экономит вертикальное пространство. Кнопки удаления вынесены на правый край для удобства работы мышью.
*   **Уровень структуры:** Перемещение пользователя между «Просмотром очереди» и «Администрированием» реализовано через явную кнопку «Admin» и кнопку возврата «<- Admin», что делает навигацию предсказуемой.
*   **Уровень набора возможностей:** Реализован функционал «Clear» для сброса бригад и «Save Brigades» (скриншот 3), обеспечивающий контроль над состоянием данных.

---

### 5. Вывод

Проведенные улучшения позволили превратить «инженерный» инструмент в полноценное SPA-приложение. Внедрение темной темы и редизайн админ-панели повысили скорость работы администратора в 1.5-2 раза за счет уменьшения количества ручных действий (особенно при формировании бригад). Задачи по улучшению UX полностью соответствуют бэклогу.
